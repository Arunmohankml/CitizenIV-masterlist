
# CitizenIV Masterlist

A server masterlist project built for CitizenIV multiplayer, designed to display and manage available game servers in a clean and accessible way.

This  was created to support GTA IV multiplayer server discovery, helping players view active servers, connect with communities, and explore roleplay/gameplay servers more easily.
